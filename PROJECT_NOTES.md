# Project Notes

This implementation follows the supplied EWB Trainer Instructions: modular backend, CRUD, deployable service, Swagger/OpenAPI, Gemini, LangGraph, vector database research/selection, testing, README, and GitHub submission requirements.

## Important
The supplied instructions specify that students must research and justify a vector database. This project selects Chroma for local semantic retrieval. The structured source of truth remains SQLite; the vector store supports the chatbot retrieval use case.

Before submission, replace the sample data/test email if desired, configure your own Gemini API key locally, run tests, start the server, verify `/docs` and `/api/chat`, and push the repository to GitHub.
